# TerraQant

### Geospatial software. Practical intelligence.

We build tools that bring together **maps, spatial analysis, and AI** across desktop and enterprise web platforms.

## Our work

| Product | Focus |
| --- | --- |
| **MapStudio** | Desktop GIS, mapping, and spatial analysis workflows. |
| **GeoMind** | AI-assisted geospatial workflows. |
| **TerraQant Enterprise** | Our web portal platform for organizational geospatial workflows. |

Product availability, documentation, and licensing are specified separately for each published project.

## تيراكوانت

تطوّر **TerraQant** أدوات للعمل مع الخرائط والبيانات الجغرافية، وتجمع بين نظم المعلومات الجغرافية والتحليل المكاني والذكاء الاصطناعي. تشمل منتجاتنا **MapStudio** للديسكتوب، و**GeoMind** للمساعدة الذكية في الأعمال الجغرافية، و**TerraQant Enterprise**، منصة البورتال للعمل المؤسسي عبر الويب. نعمل على تسهيل استكشاف البيانات وبناء حلول مكانية عملية.
